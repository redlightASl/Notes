# 嵌入式可靠性基础7【标准测试】

 本文主要介绍板卡系统需要遵循的各类国标、流程以及相关测试方法

## 高低温测试

高温环境测试一般按照**GJB150.3A-2009**中程序I和程序II有关规定执行

低温环境测试一般按照**GJB150.4A-2009**中程序I和程序II有关规定执行

### 低温存储

将产品放入低温试验箱，在不通电情况下根据国标将试验箱设置到相应温度，湿度设置为0，存储至少4h后将试验箱温度调整为25℃，湿度为0，**待风干后从恒温箱内取出设备并上电**，测试产品外观和功能是否满足国标对应要求。部分标准要求在上电后进行产品压力测试。

### 低温启动

将产品放入低温试验箱，在不通电情况下根据国标将试验箱设置到相应温度，湿度设置为0，存储至少4h后，**直接在该温度下为产品上电**，测试产品功能是否满足国标对应要求。部分标准要求在上电后进行产品压力测试。

### 低温工作

将产品放入低温试验箱，在不通电情况下根据国标将试验箱设置到相应温度，湿度设置为0，**等待环境温度到达既定值后，为产品上电**，测试产品功能是否满足国标对应要求。部分标准要求在上电后设备持续稳定工作24h才能视为通过。

### 高温存储

将产品放入高温试验箱，在不通电情况下根据国标将试验箱设置到相应温度，湿度设置为国标规定的值，存储至少4h后将试验箱温度调整为25℃，湿度设置为国标规定的值，直接从恒温箱内取出设备并上电，测试产品外观和功能是否满足国标对应要求。部分标准要求在上电后进行产品压力测试。

### 高温工作

将产品放入高温试验箱，在不通电情况下根据国标将试验箱设置到相应温度，湿度设置为国标规定的值，**等待环境温湿度到达既定值后，为产品上电**，测试产品功能是否满足国标对应要求。部分标准要求在上电后设备持续稳定工作24h才能视为通过。

### 高低温循环工作

将产品放入高低温试验箱，**产品通电并满载工作**，根据国标规定的测试要求将试验箱温度和湿度设置成随时间变化的曲线，**持续循环调整环境温湿度**，测试产品功能是否满足国标对应要求。部分标准要求在上电后设备持续稳定工作24h才能视为通过。

## 雷击与ESD测试

雷击测试主要针对飞行器等设备中搭载的电路板卡，而ESD测试则通用于各类电子系统。主流的雷击与ESD测试标准包括：

* 美军标MIL-STD461G电磁兼容性测试
* GJB151B-2013中规定的各项，与美军标基本一致
* RTCA DO-160G，专用于机载设备的环境与试验程序标准

## 防水测试

防水测试一般按照**GB/T 4208-2017**外壳防护等级确定。该标准等效于**IEC 60529:2013**标准。但对于汽车电子、灯具家装这些具有特殊属性的产品，需要通过各自的标准试验才能确定防水等级。

防水等级由IP代码的第二位特征数字表示

| 特征数字 | 防护简述          | 测试核心原理      | 典型应用场景             |
| -------- | ----------------- | ----------------- | ------------------------ |
| **0**    | 无防护            | 无                | 室内干燥环境             |
| **1**    | 防垂直滴水        | 滴水箱            | 仓库、有顶棚的户外       |
| **2**    | 防倾斜滴水 (15°)  | 滴水箱 (设备倾斜) | 汽车内饰、也就是偶尔遇水 |
| **3**    | 防淋水 (60°)      | 摆管或莲蓬头      | 户外防雨淋               |
| **4**    | 防溅水 (全方位)   | 摆管或莲蓬头      | 浴室、一般户外电子       |
| **5**    | 防喷水 (低压)     | 6.3mm 喷嘴        | 甲板、洗车房环境         |
| **6**    | 防强烈喷水 (高压) | 12.5mm 喷嘴       | 船舱外、暴风雨环境       |
| **7**    | 防短时浸水        | 浸水箱            | 手机、手表、便携仪表     |
| **8**    | 防持续潜水        | 压力罐/深水池     | 水泵、水下灯具、潜水表   |
| **9**    | 防高温高压喷射    | 扇形喷嘴 (80°C)   | 食品加工、道路车辆清洗   |

其中IPX9为GB/T 4208-2017新增的等级
